## Descripción general del sistema
Este repositorio contiene la implementación en lenguaje SQL de la base de datos para la plataforma que gestiona las mantenciones automotrices del Taller Mecánico Mikes Ltda. El sistema administra las sucursales, mecánicos, clientes, automóviles y servicios del taller, junto con la información asociada a cada mantención realizada (sucursal, fechas de ingreso y salida, mecánico a cargo y estado).
